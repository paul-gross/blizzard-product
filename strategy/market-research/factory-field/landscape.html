What the field says

Speed is not what sets anyone apart. Dozens of solo repositories merge more than fifty pull requests a day and the busiest pass 150, where blizzard averages about twelve. A fleet that merges quickly is now easy to build. A fleet whose codebase is still in good shape after months at that pace is not, and the share that manages it falls as throughput rises.

Strain looks the same everywhere: a default branch that goes red after merge and stays red, single source files that grow into megabytes, verification logs committed by the hundred, and work that skips the pull request and lands on main.

How to read it

Columns

Throughput covers the thirty days to 2026-10-08. Lines added per day is measured over the last seven days where available; a value marked ≈ is estimated from the average size of the last hundred commits times the commit rate. Humans counts contributors with twenty or more commits after removing bots and agent accounts; a number in parentheses counts minor humans, each with under a tenth of the lead's commits.

The scores are a screen, not a verdict

Guardrails rewards a pull-request gate with tests, lint, and a type check; tool-enforced boundaries; strict typing; a substantial test suite; and disciplined commit messages. Health rewards a mostly green default branch and penalises oversized files, rework-heavy history, committed logs, root-level markdown sprawl, and direct pushes. Both read configuration and history, not design, and a borderline repository can move a bucket on one config file. Read the evidence column before quoting a placement.
